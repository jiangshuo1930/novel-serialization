# 示例项目（预演用）

这不是一本小说，是一个**故意埋了雷的最小项目**，用来在开书前确认脚本会照常报警。
不用写一个字就能跑（下面的输出是实测过的，不是设想）：

```
python <skill-directory>/scripts/series_audit.py \
  --plot <skill-directory>/examples/plot \
  --chapters-dir <skill-directory>/examples/chapters \
  --target-words 620

python <skill-directory>/scripts/style_audit.py \
  --dir <skill-directory>/examples/chapters \
  --blacklist <skill-directory>/references/ai-flavor-blacklist.md
```

## 演示 1 应该报出来什么（连载体检）

**必须改（5 条）**

| 现象 | 埋在哪 |
| --- | --- |
| 章末钩子重复：第 1-3 章连续 3 章都是「反转」 | 第 1-3 章节点 |
| 情绪连续同向：第 1-3 章连续 3 章都是「压抑」 | 第 1-3 章节点 |
| 最长连续 5 章没有爽点/微兑现 | 第 3-7 章 `payoff: 无` |
| 倒计时倒退：第 3 章 D-3 → 第 4 章 D-6 | 第 4 章节点 |
| 主线伏笔 F001 超过计划回收章 5 章 | `foreshadowing/伏笔表.md` |

**建议改（2 条）**

| 现象 | 说明 |
| --- | --- |
| 钩子类型不在标准清单里：`翻转` | 第 7 章故意把「反转」写成「翻转」，验证词表校验 |
| 第 7 章 480 字 < 目标 90%（558，**节点自报，可能不准**） | 第 7 章没有正文文件，所以只能退回自报数字——这一条专门演示"自报不可信" |

第 1 章的字数走的是**正文实测**（613 字，落在目标 620 的 ±10% 内，不报），
和上面那条自报的形成对照。

## 演示 2 应该报出来什么（单章预筛）

示例正文是故意写得很 AI 的（613 字，超过 500，所以统计项会真的跑起来）：

**必须改（3 条）**：黑名单命中 9 处（`不由得`×2、`心中暗道`×3、`嘴角勾起`、`与此同时`、
`他意识到`、`瞳孔骤然收缩`、`深吸一口气`、`空气中弥漫着`、`莫名地`）、重复开头（`他缓缓`×9、`他心中`×3）、
连续 4 句长度几乎相同。

**参考区间外（4 条）**：正文没有成对引号（通篇叙述，对话统计口径不准）、标点太齐（标点 CV 0.2 < 0.3）、
局部节奏不达标（只有 33% 的 200 字窗口同时有短句和长句，目标 90%）、单句段占比 0%（要求 15%-45%）。

## 这个示例同时也是"反例教材"

`chapters/第1章-灯下.md` 就是**不该这么写**的样子：句长齐、套话多、情绪直接命名、
每段都"他缓缓地……"。写自己的第一章之前扫一眼它，比看十条规则管用。
