# 节奏、爽点与悬念（市场侧）

> 管"读者会不会追下去"。写 beat 和定稿前看。
> 这里的内容来自网文作者社区与开源创作 skill 的规则汇编，**不是行业标准**：
> 数字之间互相冲突（单章字数 1500-5000、爽点周期 2000 字到 9000 字都有），
> 因为免费流/付费流、男频/女频完全不同。所以本文件按**平台分档**给区间，
> 开书时在 `style/风格档案.md` 里选定一档，之后按那一档校准，不要取平均值。

## 一、开篇（黄金三章已经变成黄金 300 字）

| 位置 | 必须发生什么 |
| --- | --- |
| 第 1 句 | 3 句内立危机或反差。不写天气、建筑、童年回忆、世界观说明 |
| 前 300 字 | 进入正在发生的冲突。**这是弃书率最高的位置** |
| 前 500 字 | 主角出场；开篇人名 ≤3 个、地名 ≤1 个 |
| 前 1000 字 | 金手指/核心机制落地（免费流）；付费流可放宽到第三章前 |
| 第 1 章末 | 主角已经用自己的能力做成一件具体的事。拿到优势前先写他怕/疼/屈辱，**禁止开局满级冷静** |
| 第 2 章 | 免费流：完成第一次当面打脸（轻蔑者在场 + 具体台词 + 对手失态 + 围观反馈 + 主角回一句）。付费流：立人设 + 建立目标动力 |
| 第 3 章 | 抛出第一个中期目标和第一个强敌，让读者知道下一阶段追什么 |

**头号劝退项**（两家来源都排第一）：大段设定说明文。纯设定铺垫超过两千字，弃书率直线上升。

## 二、爽点

**三段闭环**：压抑（不公要写具体）→ 蓄势 → 释放。
**打脸四拍**：嘲讽 → 沉默 → 碾压 → 围观（围观最容易被漏掉，也最爽）。

| 档位 | 小爽点 | 中爽点 | 大兑现 |
| --- | --- | --- | --- |
| 免费流（番茄/飞卢） | 每 1-2 章 | 每 3-5 章 | 每 10 章 / 每 10 万字一个卷级大爆 |
| 付费流（起点/晋江） | 每 3 章 | 每 5-8 章 | 每卷至少 1 次（通常卷末） |

- **爽点必须升级，不能原地重复**：打脸对象要往上升（同窗→长辈→宗门→天才→大势力）。同一级别的爽点重复三次以上，读者就自动免疫了
- **相邻爽点不得同类**：明爽/暗爽/误解爽/收获爽/情感爽轮换
- **大爽点要有具名情绪代理人**说出反应，禁用"众人哗然""有人低声说"
- **压抑周期上限**：连续 3-4 章没有进展，追读就掉；单次压抑周期不超过 30 章；"雪耻不过夜"——打脸反杀要快
- 反派越嚣张，打脸越爽。但**反派的冒犯必须有利益因果**（抢地/夺宝/争名），禁止莫名挑衅；反派被压制要写明现实限制或第二方案，不能无缘无故放过主角

## 三、章末钩子

- 每章至少 1 个有效钩子，**在情绪/动作/真相的前一秒断章**，绝不在最高点写完
- **类型轮换**：连续 2 章不重样，同一种不连用 3 次
- 钩子类型清单（挑着用，记账在节点文件里）：
  悬念 / 危机 / 反转 / 打脸预告 / 关系 / 升级 / 信息 / 倒计时 /
  动作中断 / 信息差 / 情绪反转 / 身份谜团
- **兑现期限分档**（来源之间冲突，这里按层级分，别取平均）：
  - 章级钩子：**1-3 章内必须兑现**，否则读者弃书
  - 卷级大钩：可跨卷，但每 20-30 章要"碰一下"提醒读者它还活着
- 上一章的钩子最迟在本章**前三成位置**回应（可以只给一半答案，同时抛新问题）
- 免费平台只展示最后 100-300 字，钩子必须落在这个窗口里

## 四、悬念与伏笔的写法

- 悬念三层同时跑：**事件悬念**（每卷至少 1 个）/ **身份悬念**（贯穿全书）/ **动机悬念**（终卷揭晓）
- 信息差分层释放，绝不一次揭晓；旧信息差揭晓前，先埋一个更大的新信息差
- 埋之前先想怎么收，**从高潮倒推埋点**
- 给伏笔挂标签（外貌/口癖/怪癖/身份），否则读者记不住 = 白埋
- 长线大伏笔用**三段刺激法**：当场完整写一次 → 中间侧面提一次 → 揭晓前复述唤醒再砸真相
- **AI 写伏笔最大的坑是"太诚实"**：写卧底不要给"眼神闪过一丝阴鸷"这种暗示。把真伏笔混在 2 个无关细节里，并且不特别描写它

## 五、弃书原因（按被提到的频次排序，逐条自检）

1. **开篇铺垫太长 / 设定说明文** —— 头号劝退
2. **爽点太慢、主角长期窝囊** —— 一直忍不反击，没有反击苗头
3. **人设崩塌、前后不一致** —— 比人设扁平更致命
4. **情节重复套路化** —— 同一结构用到第三个弧，读者就能预测全部走向
5. **钩子缺失或钩子疲劳** —— 章末收太干净，或同型连用三次
6. **毒点**：圣母白莲花、双商掉线、无脑降智反派、金手指失控、油腻种马；三观雷区（绿帽/送女/夹带私货）是封号级
7. **注水凑字数 / 对话没有个性 / 视角混乱**
8. **挖坑不填** —— "作者是不是忘了""烂尾警告"
9. **断更** —— 追读掉档、权重下降

**No-Poison 五条**（写作时的硬禁止）：

| 禁止 | 说明 |
| --- | --- |
| 降智推进 | 靠角色突然变蠢来推动情节 |
| 强行误会 | 一句话能说清却不说，只为拖剧情 |
| 圣母无代价 | 无底线善良却从不付代价 |
| 工具人配角 | 只为主角服务、没有自己动机的角色 |
| 双标裁决 | 同样的事主角做是对的、别人做是错的（除非是刻意的讽刺） |

## 六、更新与存稿（连载的现实约束）

- 日更稳定度是算法指标：多数平台要求日更 3000-6000 字稳定
- **开书前先攒 3-5 万字存稿**，连载期维持 3-5 天安全垫
- **卡文宁可降更也不要断更**：从日更 6000 降到 3000，向读者说明，暗中攒回存稿。断更一天追读掉一档
- 固定更新时间（晚 8 点或早 9 点）
- 长期日更 8000 以上几乎必然导致后期崩盘——留给"超长篇机制"的节奏判断

## 七、扩张 ≠ 注水

内容不够时**不要**用场景细节、五感、次要情节去"填"。扩张只有一个理由：**服务于冲突或信息增量**。

判断方法就一句：删掉这段，读者对剧情/人物/世界的理解会不会变？不变就是注水。
