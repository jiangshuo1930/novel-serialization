# AI 套话黑名单

定稿前必须清零。**每一处命中都要回正文改掉**，不是把清单当参考。

用法：`python <skill-directory>/scripts/style_audit.py <章节文件> --blacklist <skill-directory>/references/ai-flavor-blacklist.md`
脚本会把本文件里所有反引号包裹的词当作禁用词提取。**数值与配额的唯一权威是 `scripts/style_audit.py` 顶部的常量**，本文件是它的说明。

## 表情与眼神

| 禁用 | 为什么像 AI | 替换方向 |
| --- | --- | --- |
| `嘴角勾起` | 网文 AI 味第一名 | 写别的部位：腮帮子紧了、嘴唇抿成一条线 |
| `眸光微闪` | 抽象、可预测 | 写具体动作：把烟按灭、手指在桌沿敲了两下 |
| `眼底闪过一丝` | 万能填充 | 干脆不写眼睛，写他做什么 |
| `眼神暗了暗` | 陈词 | 写呼吸、写手上的劲 |
| `瞳孔骤然收缩` | 影视腔套话 | 写身体后仰、写声音变了 |

## 心理旁白

| 禁用 | 替换方向 |
| --- | --- |
| `不由得` | 直接删，动作自己会说话 |
| `心中暗道` | 转成直接引语或直接删掉引导语 |
| `他意识到` | 删掉，改成他做了什么 |
| `心头一颤` | 写生理反应：胃里一沉 |
| `五味杂陈` | 写一个具体的东西：他想起那年冬天的煤炉 |
| `如释重负` | 写动作：一屁股坐下，把外套扔了 |
| `莫名地` | 删。要么写出理由，要么不提 |

## 环境与转场

| 禁用 | 替换方向 |
| --- | --- |
| `空气中弥漫着` | 写单一气味源：楼下炸带鱼的味儿飘上来 |
| `与此同时` | 直接切场景，不要报幕。一次都别用 |
| 随着（句首） | 拆句，换成主谓结构。不是禁用词，但句首的"随着"是典型机器过渡 |
| `夜幕降临` | 写具体时间锚点：路灯刚亮 |
| `阳光透过窗户洒在` | 写光影落在什么物件上 |

## 叙事套话

| 禁用 | 替换方向 |
| --- | --- |
| `命运的齿轮` | 删。这话把悬念说死了 |
| `这只是一个开始` | 删。章末钩子要用事件，不用宣告 |
| `殊不知` | 删。要么直接写那件事，要么不说 |
| `然而他不知道的是` | 同上 |
| `值得注意的是` | 删，这是 PPT 语言 |
| `总而言之` / `综上所述` | 删，小说不做总结 |
| 不是……而是…… | 拆成两句，或只留后半句（结构问题，脚本抓不到，靠自己看） |

## 身体反应套话

`深吸一口气`、`倒吸一口凉气`、`浑身一震`、`头皮发麻`、`后背瞬间被冷汗浸透`
→ 换成这个角色**特有**的反应，并且全书反复用同一个（癖好要固定，不要每章换花样）。

## 程度副词与软修饰

深深地、缓缓地、微微、轻轻、静静地、默默地、紧紧地

→ **不是禁用词**，但删掉 80%。动词本身够强就不需要副词。脚本用"弱化副词密度 ≤8 处/千字"总控。

## 结尾宣告

`一切都将改变`、`故事才刚刚开始`、`他的人生从此不同`
→ 一律删。章末留钩子的正确做法：冲突悬着、反转刚冒头、新信息砸下来。

## 感情戏套话（细腻的反面）

感情只能写出来，不能报出来。这些词一出现，就是作者在替读者下结论。

| 禁用 | 替换方向 |
| --- | --- |
| `心动` | 写他做了什么：多绕了一段路、把伞往那边倾 |
| `心头一暖` | 写动作停顿：他把那碗汤喝完了才说话 |
| `心跳漏了一拍` | 写手上一顿、话断了半句 |
| `小鹿乱撞` | 删 |
| `关系升温` | 删。关系靠事件体现 |
| `暧昧不清` | 写具体行为：话说一半停了、手伸出去又收回来（单用"暧昧"形容气氛可以留） |
| `情愫` / `爱意` / `情意` | 抽象词，换成一个小动作或一件东西 |
| `脸颊泛起红晕` / `脸上一红` | 写遮掩动作：转过头、找话说、把杯子端起来 |

## 弱化副词与模糊词

**这一组是配额词，不是禁用词** —— 完全不出现反而假。

前两组由脚本按**弱化副词密度 ≤8 处/千字**总控，其中 似乎/也许/大概 另有**每 500 字 ≤3** 的单独配额；
仿佛/宛如/宛若 是过度比喻，脚本不单独统计，凭手感少用。

| 少用 | 改法 |
| --- | --- |
| 似乎 / 好像 | 要么确定，要么不写 |
| 大概 / 或许 / 也许 | 给具体数字，或让角色直接做 |
| 几乎 / 稍微 / 确实 | 写出具体差距 / 删 |
| 仿佛 / 宛如 / 宛若 | 过度比喻 → 换成具体感知，别每段都用 |

下面这几个是**禁用**（反引号会被脚本提取）：

| 禁用 | 改法 |
| --- | --- |
| `不禁` / `忍不住` | 剥夺角色主动性，直接写行动 |
| `下意识地` / `不由自主地` | 太高频，写成主动动作 |
| `一时间` | 用具体动作填时间 |

## 意义膨胀与论文体

| 禁用 | 改法 |
| --- | --- |
| `在某种程度上` / `从某种意义上说` | 删 |
| `需要指出的是` | 删 |
| `众所周知` / `毫无疑问` / `事实上` | 删或具体化 |
| `在这个过程中` | 删 |
| `综上所述` | 删，小说不做总结 |
| `映入眼帘` | 直接写看到了什么 |
| `暗自思忖` | 删，或改成行动 |
| `首先` / `其次` | 删，这是论述文结构。（"最后"是叙事常用词，不禁用） |

同时检查三件事（这些不是词，脚本抓不到，靠自己看）：

- **对称结构**：一方面……另一方面……、不仅……而且…… 连用 → 打破
- **三段式排比**：A、B、C 三个结构相同的句子连排 → 至少打破其中一段的节奏
- **正式语体**：对……进行了……、被……所……、给予了……高度评价 → 直接写动作、写口语

## 跨章重复（单章脚本查不到，最典型的"作者抄自己"）

单章脚本只看一章之内，所以下面这些要在**跨章**层面查——
由跨章一致性核对脚本负责，**每 3-5 章跑一次**：

| 症状 | 为什么像 AI | 改法 |
| --- | --- | --- |
| 同一句话在两个（尤其相邻）章里逐字出现 | 人不会连续两章用一模一样的句子回应同一个节拍 | 改掉其中一处措辞；**确属刻意回声**（主角的仪式句、核心台词）写进情节白名单（novel/state/连续性白名单.md） |
| 同一个癖好动作在 8 章里用**同一句原话**复刻 | 癖好该反复出现，但**措辞**不该逐字复刻 | 换措辞保留习惯（"把手在裤腿上擦"→"在裤子上蹭了蹭手心"），并把变体登记进 fingerprint 块 |
| 同一微动作在一章里刷 ≥3 次 | 真人不会这样自我重复 | 换写法，或删掉多余的 |
| 角色档案登记的口头禅/外貌细节**从未在正文出现** | 读者认不出他是他；档案在撒谎 | 要么写进正文，要么把登记删掉 |

> 顺带一条**汇报纪律**：脚本全绿 ≠ 没问题。报"通过"时必须同时报"脚本不查什么"
> （声纹落点、跨章重复、档案对齐、知识边界、对话占比、平台合规），
> 否则"全绿"读起来像"这章没问题"，是误导。

## 集体反应与公式化句式（中文 AI 腔的强特征）

**集体反应套话**用一群人的同步反应，代替具体的人：

- `全场震惊`、`众人哗然`、`鸦雀无声`、`面面相觑`
- 确实需要一个群体反应时，**写其中一个人的具体动作**（谁先站起来、谁把杯子放下），
  比"所有人都愣住了"有力得多

> 定这几条之前按真实稿实测过（13 章 / 28479 字）：上述四条**全书 0 处**，所以加进来零误报。
> **注意不要把「所有人都」「全场」也加进去**——它们是正常中文，加了就是误杀。
>
> **公式化对称句式**（不是……而是……／与其说……不如说……／一方面……另一方面……／
> 仿佛……一般／像是……似的）由 style_audit.py 用**正则**查——**放进黑名单没用**，
> 因为中间隔着内容，字面量匹配不到。它同样**只提示不判必须改**（偶尔用一次是修辞）。
> 实测这本书这五种句式**全部 0 处**。**「既……又……」故意不收**：它是正常中文（"既怕又恨"）。
>
> ⚠️ **本文件里凡是反引号包起来的内容，都会被当成禁用词逐条字面搜正文。**
> 所以：**只有真要禁的东西才加反引号**；讨论句式、写文件名、举例说明时一律用「」或纯文本——
> 这一节第一版就是把句式模板写成了反引号，它们立刻变成禁用条目，[1] 的"不误杀"当场报警；
> 第二版又在**这句警告里**用了反引号写 [1] 与 selftest 的节号，于是那两串也变成了禁用词。
> selftest [26] 现在会拦这类事故：黑名单里不许出现文件名、不许出现含省略号的句式模板、
> 不许出现方括号（说明性文字混进来的标记）。

## 用词配额（不是"尽量少"，是硬上限）

每章上限：突然/忽然/猛然 ≤4；竟然/居然 ≤3；渐渐/逐渐 ≤2；依旧/仍然 ≤2；
于是 ≤3；然而/不过 ≤4；瞳孔一缩/身体一僵/呼吸一滞 ≤2。
每 500 字：似乎/也许/大概 合计 ≤3。
情绪词（愤怒/难过/害怕/紧张……）单章 ≤3 次。

（`与此同时`、`倒吸一口凉气` 不设配额 —— 它们在上面是禁用词。）

style_audit.py 会自动统计并报出超标项，不用手数。

## 自查

- [ ] 黑名单命中数为 0
- [ ] 连接词密度 ≤ 3 处/千字（style_audit.py 会给数值）
- [ ] 同一个套话没有换个马甲又出现（如 `嘴角勾起` → `唇角上扬`）
- [ ] 这一章至少有一个只有本书会写的细节
