# 正文写作技术

> 写正文（第二步）时读。这里是把"人味"落到句子上的可执行手法。
> 综合参考：海明威冰山理论、Stephen King《On Writing》、Roy Peter Clark《Writing Tools》，
> 以及开源创作 skill 的实战规则（novel-writer-skills 的 authentic-voice、workbuddyskills 的
> novel-humanizer-rules、limuxue0/awesome-novel-skill、yingzhu77/my-skills）。

## 一、四大死亡气味（写完先按这四条闻一遍）

| 气味 | 症状 | 解药 |
| --- | --- | --- |
| **均匀感** | 每段都 3-4 句、每句都 15-25 字 | 段落长短交替（1 句段 + 5 句段 + 3 句段）；每 200 字内必须出现 1 个 ≤5 字短句和 1 个 ≥20 字长句 |
| **解释感** | 情绪直接命名、意图明说、比喻还要解释 | 情绪用行为、意图用选择、比喻抛出去不解释 |
| **安全感** | 比喻全是水/火/风，形容词全是最常见的 | 比喻要具体、意外、角色化（见第四节） |
| **模板感** | 场景都按"环境→人物→对话→心理"顺序 | 场景从任意角度切入；结尾类型轮换；外貌不每次出场都写 |

## 二、情绪不写标签（替换表）

| 不要写 | 改写成 |
| --- | --- |
| 他感到紧张 | 他把烟点反了两次 |
| 她很害怕 | 她的指甲掐进了掌心 |
| 他很愤怒 | 他没说话，只是把杯子放到了桌上。声音很响 |
| 她很难过 | 她在便利店站了很久。最后什么也没买 |
| 他很无奈 | 他笑了一下，很快就不笑了 |
| 心跳加速 | 她的耳朵开始嗡嗡响 |
| 呼吸困难 | 他发现自己一直在憋气 |
| 心里发慌 | 她突然想吃点酸的东西 |

**身体反应预算**：每种情绪先备 5-8 个反应写进角色档案；**通用身体反应**（心跳、倒吸凉气、瞳孔一缩、后背发凉）每 10 章同一个最多用 2 次 —— 反复用的是**这个角色专属的癖好动作**，不是通用反应。区分清楚，别搞反。

## 三、对话

- **标签删到 30% 以下**：能靠上下文看出谁在说，就不要"他说""她回答"。用动作代替标签
- **标签要朴素**：保留的标签里，`说/道/问` 应占 80% 以上；`愤怒地说`、`温柔地笑了` 这种情绪标签一律删
- **连续纯问答不超过 8 句**（密集对话段放宽到 12 句），中间插沉默、动作或环境音
- **对白节奏三武器**：沉默（该不说话时就不说话）、动作打断（话到一半伸手去拿包）、环境音（楼下汽车鸣笛）
- **潜台词**：台词 ≠ 真意。"我没事" = 你别问；"你随便吧" = 你最好选我能接受的。写每句台词前多想一层：他为什么说这句、他真正想要什么
- **不完整原则**：允许打断、改口、忘词、答非所问、跑题

## 四、比喻

三原则：**具体**（能想象出画面）、**意外**（跨类别，不在同一域）、**角色化**（符合 POV 角色的认知——程序员和屠夫的比喻不一样）。

| 安全比喻（删） | 具体 + 意外 + 角色化 |
| --- | --- |
| 她的眼睛像星星一样明亮 | 她看人的时候像在验货 |
| 他的心情像被乌云笼罩 | 他突然想给一年没联系的同学发消息 |
| 时间过得很慢 | 那十分钟里他看了七次手表 |
| 她笑得很美 | 她笑的时候，旁边那个男生的耳朵红了 |
| 风吹乱了她的头发 | 一阵风吹来，她下意识把头发塞到耳后，又想起这是别人爱做的动作，把头发拉了出来 |

**白描比比喻更有力**：不是每段都要比喻。关键时刻一个，胜过满篇泛滥。

## 五、五感与场景切入

- **五感嫁接**：视觉 + 时间记忆、嗅觉 + 情感、听觉 + 联想、触觉 + 身份认知、味觉 + 童年
- **反公式化**：不写"空气中弥漫着咖啡的香味"，写"她进门就闻到那股咖啡味——是他没喝完的那杯，应该已经凉了"
- **场景切入多样化**：不要总从环境描写开始，可以从对话、动作、声音、内心、一个问句，甚至无背景直接进入冲突
- **物理性原则**：真人有身体——渴、饿、累、痒、想上厕所。这些不会消失，应该出现在场景里
- **当下原则**：人不会突然想起 5 年前的具体细节，除非有触发；记忆是片段化、跳跃的

## 六、真人七原则（对话与内心独白通用）

1. **不完整**：说话思考都不完整——中断、改口、跑题、忘词
2. **重复**：重要的事会重复说 2-3 次，有口癖
3. **跑题**：从 A 说到 Z 才绕回 A
4. **延迟**：不会立刻回答——沉默、走神、再问一遍
5. **错误**：会说错话、用错词、叫错名字，然后自我纠正
6. **物理性**：身体需求出现在场景里
7. **当下**：活在当下，不凭空回忆

## 七、信息去重与密度

- **同一事实最多出现两处**：对话、内心、动作/记录，三者中选两个，绝不三处都写一遍
- **信息密度三问**（每段自查）：这句话能删吗？能原样搬到别的章节吗？是不是说了等于没说的正确废话？——能删的句子多 = 信息密度不够
- **允许逻辑跳跃**：不要句句衔接严密。检测器会把"从头到尾接得过于紧密"当成 AI 特征，人写作本来就有自然的跳跃
- **每章至少一个新信息增量**：读者只有这本小说能拿到的东西（新设定、新关系变化、新底牌）。全是"正确废话"会被判低创作度

## 八、角色声纹

- **辨识度测试**：随机抽 3 段，遮住角色名，能看出是谁的视角/谁在说话吗？看不出 → 回炉
- 每个角色的**句长习惯、口头禅、称呼方式、常用词**写进角色档案的"语言指纹"，并保证**每章至少出现 2 次**标志性语言或癖好动作
- 内向的人不会突然长篇大论；文化程度低的人不会用书面语

## 九、朗读测试

写完每个场景**读一遍**（心里默读也算，但要读出声的节奏）：

- 读起来像真人说话吗？
- 节奏有起伏吗？
- 哪里读着"卡"？——卡住的地方就是要改的地方
