## front-matter 取值表（用清单外的词会让轮换检查失效）

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `hook_type` | 悬念 / 危机 / 反转 / 打脸预告 / 关系 / 升级 / 信息 / 倒计时 / 动作中断 / 信息差 / 情绪反转 / 身份谜团 | 章末钩子类型，**避开最近 2 章用过的** |
| `opening_type` | 对话 / 动作 / 声音 / 环境 / 内心 / 悬念 / 物件 / 群像 | 本章开头切入方式，**避开最近 3 章用过的** |
| `payoff` | 小爽点 / 中爽点 / 大兑现 / 无 | 本章的兑现 |
| `payoff_strength` | **1-7**（≥4 才算大兑现） | 脚本按 ≥4 判定"每 10 章至少一次大兑现" |
| `emotion` | 自由但同类同词（压抑 / 紧张 / 轻松 / 爽 / 无奈…） | 连续 3 章同向会被警告 |
| `hook_strength` | 1-7 | 钩子力度，用于回看哪一章断得好 |
| `countdown` | `D-5` / `D+3` / 留空 | 倒计时用 `D-N`（剩 N 天，数字递减才对）；已过天数用 `D+N` |
| `strand` | 主线 / 支线名 | 对应总纲的 strand 划分 |
| `subplots` | 支线名，逗号分隔 | 每条支线每 8 章至少出场一次 |
| `words` | 可选 | 只是自报数；`--target-words` 门禁优先数 `chapters/` 里的正文实测字数 |

> **`countdown` 只收"单向、不会被改期"的死线。** 两种常见情况都有标记可用：
> - **同一死线被人为推后**（如名单上的日期被改期）→ 值后加 **`（可延期）`**，跳过单调性检查
> - **换了一条全新死线**（上一条办完，新案子又来一条）→ 值后加 **`（重置）`**，序列重新起算
>
> 可被第三方改期的死线**根本不要进这个字段**，记在 `plot/时间线-第X卷.md` 的正文里。
> 不写标记的新死线会被判成"倒计时倒退"（真实踩过，见 `skill-changelog.md` B014）。

front-matter 里没有 `span`/`gap` 也可以留，脚本不读它们，但填了方便自己回看时间账。
