# 风格档案

> ⚠️ **本模板里的每一个数字都是占位符，不是标准。** 它们是别人家作品的快照，
> 照抄会出事——真实项目里"平均句长 15-18 字"被照抄，实测却是 11.8（短句流）；
> "对话占比 45%-60%"也被照抄，实测均值 25%，一直没人发现。
>
> **规矩：开书头 3-5 章跑完检测后，把本文件里每一个数字都换成本书实测值，
> 并且一次做完——只修脚本报出来的那一项，剩下的会一直挂着。**
> 每项写成「本书基线 N ／ 门槛 M」的形式，别只留一个孤零零的数字。
>
> **另外：字数有两套口径，必须当场写死。** 脚本的 `chars`（去标点空白）与
> 平台后台字数（含标点）差约 **1.2 倍**。写清换算关系，例：
> `单章目标 2600（平台口径，含标点）＝ 2160（脚本口径，供 --target-words）`。
>
> **字数上限是可选项。** `series_audit` 只判下限（低于目标 90% 提示"骨架感"），
> **超上限不判、不提示**。想章节长度统一就自己盯；作者明确说"长章不算问题"时就别管上限。
> **下限不要关**——它挡的是骨架章，那才是真问题。
>
> 这份文件决定"几百章之后是不是同一个人写的"。每章定稿前对照最后 4 个问题自检。
>
> **数字的唯一权威是 `scripts/style_audit.py` 顶部的常量**，本文件里的数字是它的默认值快照。
> 两类要分清：
> - **硬门槛**（黑名单、用词配额、禁止矛盾、单段字数、连续同长度句、连续纯对话）与文本长度无关，违反了就改
> - **参考区间**（句长/段长波动、MATTR、3-gram、标点分布、声纹次数）与题材和字数相关，**跑满 10 章后**
>   用 `python <skill-directory>/scripts/style_audit.py --dir novel/chapters --write-baseline novel/state/风格基线.json`
>   建立本书基线，之后看漂移比看绝对值准（脚本至少要求 3 章，不够会拒绝）
>
> 词汇丰富度用 **MATTR**（滑动窗口平均 TTR）、3-gram 用**定长窗口重复率**——两者都是长度归一化的，
> 所以高潮章和过渡章之间可以直接比较。
>
> 所以下面每一项都写成"目标值 ____"，由你按本书实测填，不要照抄。
> **填完之后回头核一遍：这一页上还有没有没被实测值替换掉的占位符？没有才算填完。**

- 禁止：连续 4 句长度几乎相同（±2 字）

## 段落习性

- **段长波动系数 ParaCV ≥ 0.30**（真人区 >0.40）
- **单句段占比 25%-45%**（至少落在 15%-45% 内）
- 单段建议 ≤250 字，硬上限 400 字
- 每段平均"了"≤2.5 个
- 换行习惯：对话独立成段？动作与对话是否同段？

## 用词癖好

- **词汇丰富度 MATTR ≥ 0.40**（真人区 >0.48；MATTR = 500 字滑窗平均 TTR，与字数无关）
- **3-gram 窗口重复率 ≤ 0.08**（500 字滑窗；同样与字数无关）
- **标点分布多样化**：标点 CV ≥ 0.30；正文统一用弯引号 `“”` 或统一用 `「」`，**不要混用**（混用会让对话统计失真，脚本会提示）
- 高频自用词（反复用，别换花样）：
- 比喻取材范围：生活化 / 冷硬 / 自嘲 / 行业黑话 —— 选 1-2 个，别混着来
- 禁用词：见 `ai-flavor-blacklist.md`
- 量化上限：连接词 ≤3 处/千字；弱化副词 ≤8 处/千字；情绪词 ≤3 次/章

## 感情戏写法（细腻是硬要求）

- **只写小事**：感情线只能靠具体细节推进——改称呼、没接住的手、多买的一份饭、记错的偏好、替对方留的那盏灯。不写"心动了""关系升温了"这类总结句
- **一场戏只推一小步**：本作的感情推进节奏：___（如 第X章 改口 / 第X章 第一次并肩 / 第X章 坦白）
- **禁止旁白下结论**：让读者自己看出来，作者不解释两个人是什么关系
- **每个角色表达感情的方式不同**（写清差异）：A 用做事 / B 用嘴 / C 用沉默 / D 用找茬
- **感情推进必须由事件带来**，不能靠"时间久了自然就近了"
- **亲密的写法**：不写器官和动作流程，写注意力落在哪儿
- **细腻的反面**：形容词堆叠、心理直白、一次把感情推到底

## 检查档位（token 取舍）

开书时定好，每章写前声明用哪一档：

| 档位 | 用在 | 做什么 |
| --- | --- | --- |
| `QC_FULL` | 重点章：卷首卷末、爽点大兑现、转折章 | 预筛 + 朱雀 + 一致性全检 + 连载体检 + 复审到收敛 |
| `QC_CHECK` | 常规章 | 预筛 + 一致性自检 + 连载体检 |
| `QC_SKIP` | 过渡章、赶路章 | 只做黑名单与事实核对，朱雀留到下一批一起测 |

## 每章风格自检

1. 这一章有没有一句"只有这本书会这么写"的句子？
2. 段落长度和句长有没有明显的落差段（1 行段 + 40 字长句）？
3. 有没有旁白态度，还是通篇中立陈述？
4. 有感情戏的话：是不是只写小事、只推一小步，且没有旁白替读者下结论？
