# 半本书才开始用这套技能：逆向建档规程

> 适用场景：已经写了若干章（自己写的、或接手别人的稿），但 `novel/` 里没有任何档案。
> 目标**不是"完美重建"**，而是：建一套**能接着往下写**的骨架，并把"已发生"钉死。
>
> 做法参考 InkOS 的 `import chapters` 流程（它读**全部**章节、逐章顺序回放），
> 但按我们的 markdown-only 结构重写。**只借流程，不抄代码（AGPL）。**

## 三条铁律

1. **已发生的就是已发生的**：只登记正文里**已经写出来**的事实；**未收束的悬念一律留 open**。
2. **不许据文风或悬念外推未来**：资料只是证据，**不是臆造缺失设定的许可**。
   "读者觉得这里该埋伏笔" ≠ 作者埋了伏笔。
3. **正文一个字都不改**。逆向建档只产出档案，不产出正文；**不重写、不润色、不补写已有章节**。
   （作者的补写授权只适用于**新写的章**，见 `skill-changelog.md` 的 P004。）

## 步骤

### 1. 确定性切章（不靠人、不靠模型）
- 已经是 `chapters/第N章-标题.md` 就直接用；
- 若是一整个大文件，按 `第X章`／`第X回`／`Chapter N`／自定义正则切分，**先切再读**；
- 产出「来源章号 → 标题 → 实测字数」目录。**字数一律用脚本实测**（`series_audit` 的口径），
  不要手抄、也不要信平台后台那个数（两者差约 1.2 倍，见 SKILL.md 的字数口径）。

### 2. 建骨架，不做全量重建
只产这 5 类文件：

| 文件 | 建档时的要求 |
| --- | --- |
| `outline/卷纲-第1卷.md` | **只写"已发生"的那一卷**；未来卷留空——别编 |
| `characters/*.md` | 只收**具名且有戏**的角色。每张 150-250 字：当下动机／已知信息／关系压力／能力边界。**不复述整篇情节，不把"值班员"这种岗位写成传记** |
| `plot/时间线-第X卷.md` + `plot/节点-第N章.md` | 每章一行 + 每章一份节点（必填字段先填**填得出来的**，填不出的留 `待补`） |
| `foreshadowing/伏笔表.md` | **只登记未回收的**；每条必须带 埋设章／计划回收章／最近推进章 |
| `style/风格档案.md` + `state/风格基线.json` | 用 `--write-baseline` 拿**实测**数字建基线，别抄模板数字 |

### 3. 按顺序回放（这一步是关键）
从第 1 章到最后一章逐章补档案，**每章只提交"这一章新增/改变了什么"**：

- 时间线加一行；节点写事件与人物状态变化；伏笔表 upsert／推进／回收；关系表改称呼与关系
- **正文原文保留**：建档是"外部记录"，不产生新的正文版本
- **每章做完可以中断**，下次从最后完成的章号续跑（所以每章都要落盘，不能攒着一起写）

### 4. 交付前给人确认一次
把 `总纲` 的创作宪法 + 卷纲 + 角色卡清单给作者过一遍。
**这是整个流程里唯一值得设闸门的地方**——档案定错了，后面几十章都建在错地基上。

## 明确不要做的

- 不要为了"档案看起来完整"去猜没写出来的设定（宁可留 `待补`，`continuity_check` 会提示必填字段）
- 不要把"提到了"当成"推进了"（`最近推进章` 只在**确证有实质推进**时才更新，见 B024/B023）
- 不要重排正文、不要润色、不要给已有章节补写
- **不要一次性把全部章节读进上下文**：逐章回放，每章只读该章 + 当前档案
  （加载等级与牺牲顺序见 SKILL.md）

## 建档完成后怎么验收

```bash
python <skill-directory>/scripts/selftest.py                      # 脚本本身可用
python <skill-directory>/scripts/series_audit.py --plot novel/plot --target-words <目标>
python <skill-directory>/scripts/continuity_check.py --novel novel
python <skill-directory>/scripts/style_audit.py --dir novel/chapters \
  --write-baseline novel/state/风格基线.json \
  --blacklist <skill-directory>/references/ai-flavor-blacklist.md
```

`series_audit` 与 `continuity_check` 报出的"缺失字段／悬空引用／章号对不上"就是建档待补清单，
**按它逐条补完再开写下一章**。
